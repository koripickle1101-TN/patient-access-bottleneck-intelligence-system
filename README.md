# Patient Access Bottleneck Intelligence System™

**Student-developed, simulated, educational, no-PHI healthcare operations portfolio project.**

Created by Kori Pickle, Bachelor of Science in Healthcare Administration candidate, University of Phoenix (degree in progress). No formal healthcare employment experience.

## Project Title
**Patient Access Bottleneck Intelligence System™**

## Category
Patient Access | Eligibility | Workflow Control

## Short Portfolio Description

> Student-developed, simulated, no-PHI healthcare operations project designed to trace where a front-end patient-access workflow first loses control. The project connects registration inaccuracies with eligibility mismatches, authorization readiness, financial clearance, follow-up, escalation, patient communication, and verified closure.

## What Recruiters Should See

> **What I built:** An Excel-based workflow map, simulated case-control tracker, accuracy-control checklist, and dashboard.
>
> **What I practiced:** Workflow mapping, data-quality review, prioritization, ownership, follow-up, escalation logic, documentation, closure controls, and interpreting simulated operational metrics.
>
> **Why I built it:** To practice understanding how an upstream patient-access issue can create downstream delays and rework before I have access to real employer systems or healthcare data.
>
> **Important:** This is a student-developed, simulated, educational project. It contains no PHI and does not represent professional healthcare employment, live patient registration, payer-portal work, EHR use, or actual operational results.

## Workbook Structure

- **START HERE** — Project purpose, simulated problem, and what the artifact demonstrates.
- **WORKFLOW MAP** — Step-by-step front-end failure path from scheduling through registration, eligibility verification, authorization readiness, financial clearance, and patient communication.
- **CASE CONTROL** — Simulated case-control tracker with ownership, priority, next action, follow-up, escalation, communication, and closure status.
- **ACCURACY CONTROLS** — Completeness, consistency, documentation, ownership, and final-check controls.
- **DASHBOARD** — Formula-driven summary of open cases, escalations, and stage distribution.
- **EVIDENCE GUIDE** — Honest translation of the workbook into recruiter-facing language without overstating experience.

## How This Fits the Portfolio

This is a Track 1 featured project focused on patient access and front-end workflow control. It complements EVIS (Eligibility Verification Intelligence System) by showing how a single registration inaccuracy can cascade through eligibility, authorization readiness, and financial clearance.

## Overview

This Excel workbook practices tracing where a front-end patient-access workflow first loses control. It connects a simulated registration inaccuracy with downstream effects on eligibility matching, authorization readiness, financial clearance, follow-up, escalation, patient communication, and verified closure.

**Category:** Patient Access | Eligibility | Workflow Control
